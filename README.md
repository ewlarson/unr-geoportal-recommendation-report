# Nevada Historical and Environmental Geospatial Repository

This repository documents the Technical Architecture and Sustainability Roadmap for the University of Nevada, Reno's proposed statewide geospatial repository. Prepared by Eric Larson in support of the IMLS-LSTA strategic planning grant, *Building on a Legacy of Connecting People to Place*, the report evaluates metadata standards, cloud-optimized assets, geoportal platforms, implementation costs, and the staffing and governance needed to sustain access to Nevada's historical maps, imagery, and environmental data.

The recommended architecture combines OpenGeoMetadata Aardvark metadata, the community-sponsored OpenGeoMetadata API, a configurable React frontend, and cloud-optimized derivatives delivered from S3-compatible object storage. Archival originals remain under institutional preservation controls, while COG, PMTiles, and IIIF assets support public previews and downloads. The [UNR discovery prototype](https://opengeometadata.org/ogm-discovery/unr/#/) demonstrates this approach alongside OpenGeoMetadata Studio's metadata curation and publishing workflows.

The roadmap recommends a representative pilot followed by phased implementation, with a provisional five-year budget of $300,000 including contingency. Production launch depends on confirmed service ownership, recurring support, preservation responsibilities, and accessibility and security validation. GeoBlacklight remains the established alternative if the emerging shared API cannot meet UNR's operational requirements; portable metadata and independently managed assets preserve flexibility whichever platform is selected.
